# 缠析 · 操作手册

缠析是一款缠论学习工具。你可以观摩带讲解的行情片段、动手练习分解、记笔记、
把学习成果整理成图文分享出去，也可以导入自己的数据来看。

本手册只讲**怎么操作软件**，不讲缠论理论本身。

---

## 一、界面总览

打开软件后，界面分三块：

**顶栏**（最上面一条）

| 按钮 | 作用 |
|---|---|
| 缠析图标 | 应用标识 |
| 侧栏开关 | 收起／展开左侧栏。收起后主区域更宽，适合专心看图 |
| 切换视图 | 在学习、练习、自研之间切换。**侧栏收起时靠它导航** |
| 命令面板 | 打开命令搜索框，快捷键 `Ctrl+K` |
| 面板开关 | 控制右侧辅助面板（讲解、笔记）的显示与隐藏 |
| 设置 | 关于、隐私选项 |
| 帮助 | 打开本手册 |

**左侧栏**：上半部分是视图导航（学习／练习／自研），下半部分是当前视图的
清单，比如学习视图下就是你的片段清单。

**主区域**：图表和内容。右侧可以拉出辅助面板放笔记、讲解和讨论。

侧栏和面板都能拖动边缘调整宽度，下次打开还是你调好的样子。

---

## 二、学习：看带讲解的片段

这是最主要的用法——看一段真实行情，配合讲解理解它是怎么被分解的。

### 添加片段

1. 切到**学习**视图
2. 点清单标题右侧的 **+**
3. 弹层里列出可添加的片段，输入代码或名称能过滤（比如输入 `沃尔` 或
   `sz002130` 都能找到沃尔核材）
4. 点**加入**下载安装，装好后出现在左侧清单里

清单为空时，中间会有一个"添加片段"按钮，点它同样能打开这个弹层。

### 看片段

点清单里的任意一条即可打开。图表会显示这段行情和它的完整分解结构。

右侧面板有两个页签：

- **讲解**——逐步文字说明，按结构出现的先后顺序讲；
- **笔记**——你自己的学习笔记（见第四节）。

面板看不见的话，点顶栏的面板开关打开。

### 片段更新

片段内容有新版本时，清单顶部会出现一条提示，比如"3 个片段有新版本"。点
**全部更新**即可：

- 全部成功——提示条消失，说明更新完了；
- 有失败——提示条变红并列出是哪几条没成功，按钮变成**重试**。

### 移除片段

清单项右侧的 **−** 号从清单移除。片段本身还留在本机，之后在添加弹层里重新
"加入"就能立刻恢复，不用再下载一次。

## 三、练习：自己动手分解

练习是**盲练**——只给你 K 线和线段作为已知条件，走势划分和中枢要你自己画，
画完对答案、自动打分。

### 准备题目

练习片段和学习片段是**分开的两套**，互不混杂。练习片段必须带难度档位
（幼儿园／学前班／小学），没有档位的片段不会出现在练习里。

切到**练习**视图，点 **+** 添加。如果弹层是空的，说明目前还没有带档位的
练习片段可用。

### 做题

1. 从清单选一道题打开，卡头显示**作答中**
2. 用标注工具画出你认为的走势和中枢：
   - **走势**画折线，端点会自动吸附到线段端点上
   - **中枢**画矩形
3. 画完点**对答案**

对完答案后：

- 卡头变成**已对答案**，提示行显示得分和明细；
- 图上同时显示你的答案和标准答案，可以直接比对；
- 想再来一次点**重新作答**。

成绩保存在本机，登录状态下也会同步到服务器。

**说明**：练习时图表的结构显示快捷键（线段 `Ctrl+D`、中枢 `Ctrl+H`、
走势 `Ctrl+W`、买卖点 `Ctrl+M`）被关掉了——盲练不能直接把答案调出来看。
缩放、平移、换周期、成交量、MACD、结构编号这些正常可用。对完答案后全部恢复。

---

## 四、笔记

笔记是**私有**的，只有你自己能看到。

- 学习视图下的笔记挂在**片段**上——每个片段一组笔记；
- 自研视图下的笔记挂在**你导入的数据**上，纯本地存储，不联网也能用。

笔记支持 Markdown，写完自动渲染。删除时点两下**删除**确认（第一下变红提示，
2.5 秒内不点第二下就自动取消，防误删）。

笔记可以带进分享——见第五节。

---

## 五、分享：把学习成果整理成图文

分享中心把你的截图和文字整理成一份可以直接发出去的内容。

**注意**：缠析不会替你发到任何平台，只把内容备好，你自己复制粘贴到想发的
地方。

### 攒图

- 顶栏或图表上的**分享**按钮打开分享中心；
- 更方便的是快捷键 **F8**——随时把当前图表截一张进图篮，不打断你看图。
  截图会自动带水印。
- 图篮里的图**跨片段保留**，看完几个片段攒够了再一起整理。屏幕上有个浮动
  徽标显示当前篮里几张，点它直接打开分享中心。

### 整理

分享中心是左图右文的布局：

- 左边是图篮，每张图能加图注，也能删掉；
- 右边是文案区，包含标题、你勾选的笔记、引用的讲解、图注清单和落款。

组好之后复制走，或者把图片保存下来。

### 创作模式

按 **F9** 收起所有面板、图表满屏，专心看图截图。再按一次恢复。

---

## 六、自研：导入自己的数据

**自研**视图用来看你自己的数据。

支持两种来源：

- **通达信目录**——选中本地通达信的数据目录导入；
- **CSV 文件**——按标准列格式的文本文件。

导入后数据存在本机，图表照常显示。

**隐私**：导入的数据只读取、只存本地，**永远不会上传**。基于这些数据写的
笔记同样只存本机。

---

## 七、图表操作

图表是你看盘和练习的主要界面。这一节讲**怎么操作**——看到什么、点哪里、按什么键。

图表底部常驻一条**快捷键提示栏**，列着最常用的键。不用记，忘了低头看一眼即可。

---

### 看清楚：缩放与平移

**放大缩小 K 线**

| 操作 | 效果 |
|---|---|
| 滚轮 | K 线变宽 / 变窄 |
| `Shift` + `↑` `↓` | 同上，一次一档 |
| `Ctrl` + `Z` | 恢复默认宽度 |

K 线宽度可以一直压到很窄，用来看长期走势的全貌；也可以拉宽到看清每一根的形态。

**左右移动**

| 操作 | 效果 |
|---|---|
| 鼠标拖拽 | 按住图表往左右拖 |
| `←` `→` | 移动 3 根 |
| `PageUp` `PageDown` | 移动半屏 |
| `Home` | 跳到最早 |
| `End` | 跳到最新 |

`PageUp`/`PageDown` 移动的是**半个屏幕**，所以你把 K 线压得越窄、一屏显示越多，一次翻过去的时间跨度就越大。

按 `End` 回到最新时，右侧会留出一小段空白，方便看清最后几根。

---

### 换周期

同一段行情可以按不同的时间尺度看——1 分钟一根、5 分钟一根、一天一根……

| 操作 | 效果 |
|---|---|
| `↑` 或 `+` `=` | 换成更大的周期（看得更远） |
| `↓` 或 `-` | 换成更小的周期（看得更细） |
| `Ctrl` + 滚轮 | 同上 |

图表左上角始终显示当前周期。

**周期和 K 线宽度是两件事**：换周期改的是"每根 K 线代表多长时间"，缩放改的是"每根画多宽"。想看更长的历史，两种办法都行——压窄 K 线，或者换大周期。

---

### 读数：十字线

鼠标移到图上会出现十字线，跟着它你能看到：

- **图表左上角**：这根 K 线的开盘、最高、最低、收盘和涨跌幅
- **卡片顶部**：同样的读数，位置更醒目
- **坐标轴上**：十字线对应的具体时间和价格

鼠标移出图表，读数会自动清空。

---

### 显示什么：图层开关

图上画的每一类东西都能单独关掉。**看不清的时候，关掉几层往往比放大更有效。**

| 快捷键 | 控制 |
|---|---|
| `Ctrl` + `D` | 线段 |
| `Ctrl` + `H` | 中枢 |
| `Ctrl` + `W` | 走势 |
| `Ctrl` + `M` | 买卖点 |
| `Ctrl` + `V` | 成交量 |
| `Ctrl` + `I` | MACD 副图（**默认关着**） |

MACD 默认不显示，想看得按 `Ctrl` + `I` 打开。

**按级别显示**

结构分不同级别，从小到大排列，用不同颜色区分。

- `Ctrl` + `1` 到 `Ctrl` + `8`：按级别顺序，逐级开关

比如只想看大级别的结构，就把前几级关掉。数据通常只有前三四级，按更大的数字不会有反应。

**结构编号**

`Ctrl` + `N` 打开编号显示。按完 `Ctrl` + `N` 后，**1.5 秒内**再按一个数字，可以只显示某一类的编号：

- 按 `0` → 只显示段号
- 按 `1` 到 `8` → 只显示对应级别的编号

单按 `Ctrl` + `N` 不接数字，就是全部编号的总开关。

---

### 两种看法：精简 / 完整

`Ctrl` + `T` 在两种显示方式之间切换：

- **精简**（默认）：只画本级别真正成型的结构
- **完整**：把所有记录在案的都画出来，包括那些和下级重复的

平时用精简就够了。完整模式主要用来核对——当你想确认"某条结构到底记没记"的时候。

切换时图上会短暂提示这次隐藏或显示了多少条。**如果提示"0 条"，说明当前这段本来就没有可隐藏的内容**，不是按键没生效。

---

### 结构怎么长出来的：渐进显示

`Ctrl` + `P` 打开渐进显示。

打开后，图表只画出"到当前画面右边缘为止已经确认的结构"。你把画面往右滚动，就能看到结构随着 K 线一根根进来**逐步出现**的过程——什么时候成立的，就什么时候出现。

这是练习判断时机的主要工具：在结构还没成立的位置，你看到的和当时的人看到的一样多。

再按一次 `Ctrl` + `P` 关闭，恢复显示全部结构。

**虚线与实线**：图上的走势线有两种画法。**虚线**表示这条走势**还没有被
确认**——它已经成立，但后面的走势还没出现，所以它仍可能继续延伸。**实线**
表示已经确认：下一条走势诞生了，这条就定型了。

渐进模式下你会看到同一条走势先以虚线出现、逐段延伸，直到某一刻变成实线
——那一刻正是下一条走势诞生的时刻。

---

### 跳到指定位置

`Ctrl` + `G` 打开一个小输入框，输入段号回车，图表会跳到那一段，并把它放在画面靠左的位置——方便你看它之后发生了什么。

---

### 在图上作标注

图表支持在上面画东西，用来作答或做记录。工具入口在图表上方的工具栏。

**画走势**：依次点击几个转折点连成折线。落点会自动吸附到附近的线段端点，不用点得很准。画完按 `Enter` 或者双击结束。

**画中枢**：点两下，分别是矩形的两个对角。

**其他标注**：箭头、便签文字、区间高亮等，用法都是点击或拖拽，跟着提示操作即可。

**通用操作**

| 操作 | 效果 |
|---|---|
| 点击标注 | 选中，出现可拖动的控制点 |
| 拖动控制点 | 调整形状或位置 |
| `Delete` / `Backspace` | 删除选中的标注 |
| `Esc` | 取消正在画的；没在画时退出标注模式 |
| 右键 | 打开菜单 |

你画的标注**永远显示**，不会因为缩放或图层开关而消失。

---

### 一些说明

**为什么有时候线段或中枢整层不见了？**

当 K 线压得很窄时，如果某一类结构里有跨度特别短的（只占一两根 K 线的宽度），那一整类会暂时隐藏。因为在那个尺度下它们会挤成一团竖线，看着比不显示更糊。**把 K 线拉宽，或者换个更小的周期，它们就回来了。**

**为什么按了级别开关没反应？**

数据通常只到第三、四级。按更大的数字时，那一级本来就没有内容。

**颜色的含义**

- K 线是单色的，比较暗——它是背景材料
- 结构线（走势、中枢）用彩色，按级别区分，比 K 线亮——它们才是要看的主角
- 你自己画的标注是金色的，和系统画的明显区分

## 八、其他

### 命令面板

`Ctrl+K` 打开，输入关键词搜索所有可用命令，回车执行。匹配到的字会高亮，
常用的命令会自动排到前面。

### 检查更新

有新版本时软件会提示。当前版本只做提示，不自动下载安装。

检查更新时只发送三样信息：**版本号、操作系统平台、一个匿名的安装编号**。
不会发送你看的品种、行情数据或笔记内容。

### 设置

顶栏齿轮按钮打开，包含版本信息和隐私选项。

### 快捷键一览

**全局**

| 快捷键 | 作用 |
|---|---|
| `Ctrl+K` | 命令面板 |
| `F8` | 截图入篮 |
| `F9` | 创作模式（收起面板、图表满屏） |

**图表**（鼠标在图表上时生效，完整列表见第七节）

| 快捷键 | 作用 |
|---|---|
| 滚轮 | 缩放 K 线 |
| `↑` `↓` | 换周期 |
| `←` `→` / `PageUp` `PageDown` | 左右平移 |
| `Home` / `End` | 跳到最早／最新 |
| `Ctrl+D` `Ctrl+H` `Ctrl+W` | 线段／中枢／走势 显示开关 |
| `Ctrl+V` `Ctrl+I` | 成交量／MACD |
| `Ctrl+T` | 精简／完整 切换 |
| `Ctrl+P` | 渐进显示 |

图表底部常驻快捷键提示栏，忘了低头看一眼即可。
