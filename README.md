# 缠析 (mychan)

基于缠论的 K 线走势自动分解工具。本地运行，自动完成分型、笔、线段、中枢、走势的逐级划分与买卖点标注。

## 下载

到 [Releases](../../releases) 页面下载对应平台的安装包：

| 平台 | 文件 | 说明 |
|---|---|---|
| Linux x86_64 | `缠析_x.y.z_amd64.AppImage` | 下载后 `chmod +x` 直接运行；另提供 `.deb` |
| Windows x64 | `缠析_x.y.z_x64-setup.exe` | 运行安装程序；SmartScreen 提示时选「仍要运行」 |
| macOS Intel | `缠析_x.y.z_x64.dmg` | 首次打开请右键 →「打开」（未做公证） |

每个版本附 `SHA256SUMS.txt`，可校验下载完整性：

```
sha256sum -c SHA256SUMS.txt
```
